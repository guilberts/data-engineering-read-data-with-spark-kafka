## 🚀 PySpark Generating and Consuming Kafka Data (Simulation)

This project demonstrates a **simplified data pipeline** that simulates a job using **PySpark and Apache Kafka**.  
It generates data dynamically, pushes it to a Kafka topic, then consumes the data back from the same topic. The output is displayed on the **console**, but the workflow can easily be extended to include data transformations and storage in other formats such as **Parquet, CSV,** or even insertion into a database.


---

## 📌  Steps
1. **Generate Messages** → Load the data into the Kafka Topic (`test-topic`).  
2. **Reading Messages** → Reading data from Kafka Topic (`test-topic`).  
3. **Console** → Visualizing data into the console.
